1Choose your game file

Where do I get that?

Emulator (Azahar, Citra): the game file you already play, as long as it is decrypted (the ordinary kind for emulators).

Real 3DS: on the console, open GodMode9, go to your game (cartridge or installed title), press A, pick NCCH image options, then Mount as RomFS image, and copy DA3File_3ds.cpk to your SD card. Choose that file here.

The patch fits one version of the Japanese game (CTR-P-BDNJ, title ID 00040000000F4000). The page checks this for you.

2Install the patched game data

Your patched file is ready ().

Put the file on the SD card at
luma/titles/00040000000F4000/romfs/DA3File_3ds.cpk

In Luma3DS settings (hold SELECT while booting), turn on Enable game patching. Then start the game as usual, from the cartridge or the installed title.

In Azahar or Citra, right-click the game, choose Open Mods Location, and put the file in a folder named romfs inside it:
…/00040000000F4000/romfs/DA3File_3ds.cpk

Start the game as usual. Do not load an emulator save state made with another build of the game; use in-game saves.
